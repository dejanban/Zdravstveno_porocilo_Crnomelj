# Ko se počitnice spremenijo v pustolovščino

## Zajeto besedilo

Ko se počitnice spremenijo v pustolovščino
pet., 29.08.2025 ob 08:00
Kulturni center Semič je v letošnjem letu zopet pripravil tri dni polne smeha, igre in ustvarjalnosti za otroke, ki so se udeležili počitniškega dogajanja od 25. do 27. avgusta. Otroci so preživeli nepozabne trenutke, polne novih izkušenj, spoznavanja narave in ustvarjalnosti.
Prvi dan so otroci začeli z jutranjim razgibavanjem, ki jih je pripravilo na naporen in zabaven dan. Sledile so kmečke igre v sodelovanju z Društvom podeželske mladine Metlika, kjer so preizkusili svoje spretnosti, moč in domiselnost. Za posebno navdušenje je poskrbela predstavitev PGD Semič, kjer so otroci spoznali delo gasilca in se preizkusili v gasilskih veščinah. Dogodek so zaključili s sladkim presenečenjem – sladoledom pri Neđotu, ki je bil prava osvežitev po dopoldnevnih aktivnostih.
Drugi dan so ponovno začeli z jutranjim razgibavanjem, sledile so vodne igre, ki jih je pripravil Center za krepitev zdravja Črnomelj. Otroci so uživali v igri z vodo in različnih zabavnih izzivih. Popoldne so obiskali Vavpčo vas, kjer so spoznali lokalne kmetije – Prešernove, Mihelčičeve in Lukežičeve ter izvedeli, kako poteka življenje in delo na kmetiji. Dan so zaključili z ustvarjanjem pod vodstvom umetnice ilustratorke Petre Preželj, ki je otrokom približala svet ilustracije in domišljije.
Tretji dan je bil posvečen pravljičnemu doživetju. Otroci so se pod vodstvom animatorke Maje podali na pravljično-doživljajsko transverzalo Škrateljc v Bevkah, kjer so spoznavali zgodbe in skrivnosti škratov na Malem placu. Ta pravljično-izkušenj polna tura je otrokom ponudila kombinacijo narave, igre in ustvarjalnega pripovedovanja, ki jih bo spremljala še dolgo po koncu počitnic.
Trije dnevi počitniškega dogajanja so minili v smehu, igri in ustvarjalnosti. Otroci so odšli domov polni novih doživetij, spoznanj in veselja, starši pa so z nasmehom spremljali, kako so njihovi otroci preživeli kakovosten in razgiban počitniški čas. Kulturni center Semič se staršem zahvaljuje za zaupanje in otrokom za sodelovanje, radovednost ter veselje, s katerim so soustvarjali tri dni polne igre, ustvarjalnosti in pravljičnih doživetij.
