# Zdrave navade bodo poskušali ohranjati tudi doma

## Zajeto besedilo

Zdrave navade bodo poskušali ohranjati tudi doma
ned., 22.03.2026 ob 16:00
Prvošolci OŠ Belokranjskega odreda Semič so imeli naravoslovni dan, ki je bil posvečen zdravemu načinu življenja. Obiskali sta nas Ana in Katja iz Centra za krepitev zdravja. Pogovarjali so se o ustni higieni ter o pomenu zdrave prehrane za zdravje naših zob. Skupaj so ponovili tudi pravilno tehniko ščetkanja zob.
Svoje znanje so nadgradili še s praktičnim delom, saj so sami pripravili zdrav zelenjavni namaz s skuto, sadne gosenice in osvežujoč smoothie. Ob tem so zelo uživali in z veseljem poskusili vse, kar so pripravili.
Dan je bil poučen, ustvarjalen in okusen, učenci pa so se strinjali, da bodo zdrave navade poskušali ohranjati tudi doma.
