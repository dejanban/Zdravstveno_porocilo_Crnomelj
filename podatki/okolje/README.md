# Podatki okoljske dopolnitve

Tabele CSV so prepis preglednic iz avtorskega vhodnega besedila `vsebina/okolje-20260924.md`; niso dodatne meritve. Ločilo je podpičje, kodiranje UTF-8 z BOM. Praznine in besedilne omejitve se ohranijo. Oznake `[@…]` ustrezajo ključem virov v `okolje-viri.json`. Kazalo preglednic: `tabele.json`.
